# A/B Testing: E-Commerce Product Page Optimization

## Overview
A complete A/B testing pipeline for a fictional online retailer (TechCart). The experiment tests whether a redesigned product detail page (Version B) increases the Add-to-Cart rate compared to the original (Version A).

## Project Structure

```text
ab-testing-ecommerce/
├── ab_testing_ecommerce.ipynb  # Main analysis notebook (6 sections)
├── generate_data.py            # Synthetic data generator
├── database.py                 # Data layer (SessionRepository)
├── business.py                 # Logic layer (GraphBuilder, StatsBuilder)
├── app.py                      # Streamlit dashboard (presentation layer)
├── data/
│   └── ab_test_sessions.csv    # 4,000 synthetic user sessions
└── README.md
```

## How to Run

**Step 1 — Generate the data:**

```bash
python generate_data.py
```

**Step 2 — Open the notebook:**

Start Jupyter from Anaconda Prompt and open `ab_testing_ecommerce.ipynb`.

**Step 3 — Launch the dashboard:**

```bash
streamlit run app.py
```

Opens at `http://localhost:8501` automatically.

## Covered in the Project
- Synthetic data generation with controlled ground truth
- Experimental design: hypothesis formulation, power analysis
- Chi-square test of independence, odds ratio, p-value interpretation
- Subgroup analysis (by device type and country)
- Three-tier architecture: `database.py` → `business.py` → `app.py`
- Streamlit dashboard deployment
- Plotly interactive visualizations

## Tools & Libraries
Python · Pandas · NumPy · SciPy · Statsmodels · Plotly Express · Streamlit · country_converter

## Dataset
Synthetic data generated by `generate_data.py`. Encodes realistic e-commerce conversion rates (12% control, 15% treatment), device mixes, geographic distributions, and session metadata across a 14-day experiment window. Reproducible via `numpy.random.seed(42)`.

## Architecture
This project follows a **three-tier repository pattern**:
- **Data layer** (`database.py`): `SessionRepository` — reads CSV, runs all aggregations
- **Business layer** (`business.py`): `GraphBuilder`, `StatsBuilder` — statistics and charts
- **Presentation layer** (`app.py`): Streamlit UI — displays results to stakeholders
